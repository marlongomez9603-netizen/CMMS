### SEMANA 7 — 19 de mayo de 2026 (Martes)
**Tema: Indicadores Fundamentales — MTBF, MTTR y Disponibilidad**

| Aspecto | Descripción |
|---|---|
| **Subtemas** | • ¿Por qué medir el mantenimiento? Del "apagar incendios" a la gestión basada en datos |
| | • MTBF (Mean Time Between Failures): concepto, fórmula, interpretación y unidades |
| | • MTTR (Mean Time To Repair): concepto, fórmula, interpretación y factores que lo afectan |
| | • Disponibilidad Operacional: A = MTBF / (MTBF + MTTR) |
| | • Tasa de fallas (λ) y su relación inversa con el MTBF |
| | • Ejercicios de cálculo con datos reales de planta industrial |
| **Competencia** | Implementar indicadores de gestión para evaluar la eficiencia del mantenimiento |
| **Resultado de aprendizaje** | Calcula e interpreta los indicadores MTBF, MTTR y Disponibilidad a partir de datos operativos de equipos industriales |
| **Estrategia de formación** | Clase magistral con enfoque constructivista. Ejercicios guiados paso a paso. Conexión con datos del CMMS del segundo corte |
| **Actividad presencial** | Exposición docente con ejemplos industriales contextualizados (PetroAndina, AgroVerde, MetalPrecision del CMMS). Taller de cálculo en clase: a partir de registros de fallas y reparaciones, calcular MTBF, MTTR y Disponibilidad de 3 equipos |
| **Trabajo independiente** | Investigar: ¿Cuáles son los valores típicos de disponibilidad aceptables en la industria petrolera, agroindustrial y manufacturera? Elaborar tabla comparativa con fuentes bibliográficas (4 horas T.I.) |
| **Horas presenciales** | 3 h |
| **Horas T.I.** | 4 h |

---

### SEMANA 8 — 26 de mayo de 2026 (Martes)
**Tema: OEE (Overall Equipment Effectiveness) y las Seis Grandes Pérdidas**

| Aspecto | Descripción |
|---|---|
| **Subtemas** | • OEE: las tres dimensiones — Disponibilidad × Rendimiento × Calidad |
| | • Cálculo paso a paso del OEE con datos de producción |
| | • Las "Seis Grandes Pérdidas" del TPM y su relación con el OEE |
| | • Clasificación del OEE: World Class (≥85%), Aceptable (60-85%), Inaceptable (<60%) |
| | • Ejercicios prácticos: diagnóstico de pérdidas y propuestas de mejora |
| **Competencia** | Analiza y utiliza indicadores como MTBF, MTTR y OEE para optimizar la gestión del mantenimiento |
| **Resultado de aprendizaje** | Calcula el OEE de un equipo industrial e identifica las pérdidas principales para proponer acciones de mejora |
| **Estrategia de formación** | Clase magistral + taller práctico guiado. Análisis de caso real |
| **Actividad presencial** | Exposición docente. Taller práctico: a partir de datos de producción de una línea industrial (velocidad nominal, tiempo planificado, paradas, productos defectuosos), calcular el OEE y diagnosticar las pérdidas principales. Ejercicio de análisis: ¿qué pilar (Disponibilidad, Rendimiento o Calidad) debe atacarse primero? |
| **Trabajo independiente** | Resolver ejercicios adicionales de OEE con diferentes escenarios industriales. Lectura sobre las Seis Grandes Pérdidas y su clasificación (4 horas T.I.) |
| **Horas presenciales** | 3 h |
| **Horas T.I.** | 4 h |

## HILO CONDUCTOR DEL CORTE

```
SEGUNDO CORTE                           TERCER CORTE
(Planificación)                         (Control y Medición)

Planes Preventivos ──────────────────→  ¿Funcionan? → MTBF ↑ = Sí
Órdenes de Trabajo ──────────────────→  ¿Son rápidas? → MTTR ↓ = Sí
CMMS (MaintPro) ─────────────────────→  ¿Qué datos genera? → KPIs → Decisiones
Optimización de Recursos ────────────→  ¿Cómo medirlo? → OEE → World Class
```

> **Mensaje clave para los estudiantes:** En el segundo corte aprendimos a *planificar y programar* el mantenimiento. En este tercer corte respondemos la pregunta: **¿Cómo sabemos si lo que planificamos realmente funciona?** La respuesta son los indicadores. Sin medición no hay mejora.
